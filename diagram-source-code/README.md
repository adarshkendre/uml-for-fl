## Recommended External Visualization Tools

### PlantUML (.puml files)
- **PlantUML Online**: https://www.plantuml.com/plantuml/uml/
- **VS Code**: Install "PlantUML" extension by jebbs (requires Java)
- **PlantUML Desktop**: https://plantuml.com/download

### Mermaid (.mmd files)
- **Mermaid Live Editor**: https://mermaid.live
- **GitHub Markdown**: Paste inside triple-backtick mermaid code blocks
- **VS Code**: Install "Markdown Preview Mermaid Support" extension

---

## How to Edit

1. Open any `.puml` or `.mmd` file in a text editor.
2. Modify the source following PlantUML or Mermaid syntax.
3. Paste into the online renderer to preview.
4. Export as PNG or SVG for report inclusion.
